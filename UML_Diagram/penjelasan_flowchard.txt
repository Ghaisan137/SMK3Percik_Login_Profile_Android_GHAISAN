Flowchart tersebut menggambarkan proses kerja sistem login dan daftar akun pada sebuah aplikasi.Dimulai saat user membuka aplikasi dan memilih antara login atau bikin akun. Jika user memilih bikin akun, user diminta mengisi nama, email, password, serta konfirmasi password hingga akun berhasil dibuat, lalu diarahkan kembali untuk memasukkan akun tersebut.   Sementara itu, jika user memilih login, user cukup memasukkan nama/email dan password untuk melalui proses verifikasi. Jika verifikasi gagal, user diminta mengulang input data dari awal, sedangkan jika berhasil, user akan langsung masuk ke halaman utama dan proses selesai.
